This page shows the sidebar tag pill customers can add to any page.

The **New** label next to this page in the sidebar comes from the page `tag` field:

```yaml
---
title: "New tag"
sidebarTitle: "New tag"
tag: "New"
---
```

The pill uses the site's primary color. Remove `tag` when you no longer want it.
