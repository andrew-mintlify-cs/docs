Ah, vous voici à l’intérieur de **Plain Product (no menu)**, mes amis!

Ce produit n’a **aucun** tableau `menu`. Le choisir dans le sélecteur de produit vous mène **directement** dans sa documentation — pas de menu de produit multi-colonnes. Voilà!

Mais oui, comparez avec **Product + Menu: Core API**, qui s’étend dans le sélecteur au lieu de plonger tout droit à l’intérieur.
