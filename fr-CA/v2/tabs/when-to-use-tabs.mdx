---
title: "Quand utiliser les Tabs"
description: "Page de démonstration de navigation."
---

Ah, mes amis! Utilisez les **Tabs** lorsque vos visiteurs se déplacent fréquemment entre des sections de même rang d'un unique produit.

Voici, sur ce site même, des exemples bien concrets :
- **Install Guide** — le contenu de la configuration
- **API Reference** — la documentation des points de terminaison
- **Cookbook** — les recettes

Ces trois sections, mes amis, sont des égales. Les Tabs rendent cette parenté évidente — mais oui, voilà!
