Ah, bienvenue, mes amis! Cette page réside à l'intérieur du **Tabs Product**. Quel plaisir de vous recevoir!

## Ce que vous devriez remarquer dans l'interface

1. Portez votre regard sur les **onglets horizontaux, tout près du haut** de la page (et non sur la barre latérale) :
   - **Compare Tabs**
   - **Install Guide**
   - **API Reference**
   - **Cookbook**
2. En cliquant sur un onglet, mes amis, toute la section se transforme — et, la plupart du temps, le chemin de l'URL change lui aussi.
3. Les onglets, eux, demeurent toujours visibles : voilà pourquoi vous pouvez sauter d'une section parallèle à l'autre pour le même public, avec grâce et légèreté.

## Onglets contre menus déroulants (un contraste rapide)

| | Onglets | Menus déroulants |
| --- | --- | --- |
| Où ils apparaissent | Barre horizontale en haut | Menu compact au sommet de la barre latérale |
| Idéal pour | Sections parallèles qu'on parcourt souvent (Guides / API / Cookbook) | Plusieurs sections, quand on souhaite une empreinte visuelle plus discrète |
| Indice visuel | Vous voyez toujours les onglets voisins | Vous ouvrez un menu pour choisir une autre section |

Maintenant, mes amis, basculez le sélecteur de produit vers **Dropdowns Product** et comparez : voilà! Vous verrez un contrôle déroulant, plutôt que ces onglets du haut. Magnifique, non?
