Voilà, mes amis! Cette page est nichée sous l’onglet **Comparaison des onglets** dans **v2.0**. Elle est cachée de la barre latérale pour que les pages de comparaison publiques demeurent faciles à parcourir.

## Quand les onglets sont utiles

Utilisez les **onglets** quand les sections de contenu sont des pairs — Guides vs API vs Livre de recettes — et que les usagers changent souvent de contexte. Les onglets annoncent des destinations distinctes sans tout imbriquer dans la barre latérale. Ah, quelle élégance!

Évitez les onglets si vous n’avez que deux petites pages. Dans ce cas, un simple groupe ou une liste déroulante est habituellement plus clair.

<Note>
Le Produit Onglets dans cette trousse de démarrage est un **produit de barre latérale** qui *contient* des onglets horizontaux. Ne le confondez surtout pas avec le sélecteur de produit de premier niveau!
</Note>

## Comment présenter cette section

Faites parcourir aux clients **Produits vs Menus de produits vs Listes déroulantes**, puis **Onglets vs Listes déroulantes**, puis **Quand utiliser les onglets**.

Mentionnez la **Galerie d’images et d’intégrations Capybara** comme démonstration visuelle sans rapport, afin qu’elle ne vienne pas brouiller la leçon de navigation.
