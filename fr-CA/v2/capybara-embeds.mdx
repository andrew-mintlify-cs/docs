Ah, mes amis! Cette branche met à l’épreuve les [images et intégrations](https://www.mintlify.com/docs/create/image-embeds) de Mintlify sur **30** pages anglaises — voilà!

**Chaque page liée ci-dessous utilise une photo de capybara différente** (fichiers locaux sous `/images/capybaras/unique-*.jpg`, chacun sous les 2 Mo). Mais oui, les pages en mode clair/sombre utilisent deux photos uniques.

## Techniques employées

| Style # | Technique |
| --- | --- |
| 0 | Markdown + chemin local `/images` |
| 1 | `<Frame>` + Markdown + chemin local `/images` |
| 2 | HTML `<img>` + largeur `style` en ligne |
| 3 | HTML `<img>` + `noZoom` |
| 4 | Image liée (`<a>` + `<img noZoom>`) |
| 5 | Paire d’images mode clair/sombre (deux photos uniques) |
| 6 | `<Frame>` + HTML `<img className="rounded-xl">` |
| 7 | Markdown + actif local unique |
| 8 | YouTube `<iframe>` dans `<Frame>` + image fixe unique |
| 9 | Markdown simple + chemin local `/images` |
