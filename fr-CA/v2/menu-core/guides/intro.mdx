Ah, mes amis! Vous êtes parvenus à cette page par un **élément du menu de produit** : **Menu : Guides**. Voilà!

Comment vous êtes arrivés jusqu'ici :
1. Ouvrez le **sélecteur de produit**
2. Choisissez **Produit + Menu : API principale** (il se déploie)
3. Sélectionnez la colonne ou l'élément **Menu : Guides**

Ce déploiement, mes chers amis, constitue un **menu de produit**, et non un menu déroulant de barre latérale. Mais oui!
