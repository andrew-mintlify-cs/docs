## Nouvelles fonctionnalités

**Onglets de référence SDK générés automatiquement!**

Publiez la documentation de référence de vos SDK directement à partir des outils que votre équipe utilise déjà! Cinq langages sont maintenant branchés sous la version 5.0, chacun rendu à partir d'un artefact natif de son outil de documentation :

- **TypeScript / JavaScript** — [TypeDoc](https://typedoc.org) JSON
- **Java** — [Javadoc](https://docs.oracle.com/en/java/javase/17/javadoc/javadoc.html) HTML
- **.NET** — [DocFX](https://dotnet.github.io/docfx/) ManagedReference YAML
- **Python** — sortie JSON du constructeur [Sphinx](https://www.sphinx-doc.org)
- **PHP** — [phpDocumentor](https://phpdoc.org) `structure.xml`

Chaque classe, interface, module et fonction obtient sa propre page — avec groupes de navigation, liens entre pages et indexation complète pour la recherche — sans aucune page de référence rédigée à la main! Commencez par le nouveau [guide de configuration de la référence SDK](/essentials/sdk-reference-setup) pour voir comment brancher votre artefact.

**Guide des déploiements de prévisualisation!**

Une toute nouvelle [page sur les déploiements de prévisualisation](/essentials/preview-deployments) vous accompagne à travers les URL de prévisualisation uniques pour chaque demande de tirage! Les personnes qui révisent peuvent cliquer sur un lien partageable et voir les modifications de la documentation en direct avant toute fusion en production — automatique via GitHub, manuel depuis le tableau de bord, ou par programmation via l'API Admin.

## Mises à jour

**Référence des espèces de capybaras dans la feuille de route v3!**

La [feuille de route du produit v3](/en/v3/roadmap) inclut désormais des sections de référence côte à côte pour le grand capybara (*Hydrochoerus hydrochaeris*) et le petit capybara (*Hydrochoerus isthmius*), avec taille, aire de répartition et détails sur l'habitat, ainsi qu'un tableau comparatif rapide pour vous aider à choisir la bonne espèce pour votre projet!
