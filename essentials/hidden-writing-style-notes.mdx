This page demonstrates a [hidden page](https://www.mintlify.com/docs/organize/hidden-pages) in a non-API Guides area.

It lives under a group with `hidden: true` and `searchable: true`, so it does not appear in the sidebar but remains discoverable in search and AI context.

## Example guidance

Keep sentences short. Prefer active voice. Use sentence case for headings. Bold UI labels and use code formatting for paths and commands.
